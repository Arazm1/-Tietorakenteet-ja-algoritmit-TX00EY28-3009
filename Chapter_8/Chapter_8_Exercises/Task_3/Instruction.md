## Implement an iterative version of the Binary search

Write a function that implements an iterative version of the binary search. The function accepts two parameters, the array in question and the value being searched. The function returns the index of the value if it's found or None if not found in the array.

Use two pointers/variables to limit the search area and update them adequately. Loop while the search area is big enough to hold at least one element inside it. Other than that, it is quite similar than the recursive version.
